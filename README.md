# Hospital Appointment Booking System

## Project Overview

Hospital Appointment Booking System is a web application used to book doctor appointments online. Users can register, login, view doctors, and book appointments easily.

## Features

1. User Registration and Login
2. Doctor Listing
3. Book Appointments
4. Appointment Management
5. Backend API Integration
6. Responsive User Interface

## Technologies Used

### Frontend

1. React.js
2. Vite
3. CSS

### Backend

1. Node.js
2. Express.js
3. MongoDB

## Folder Structure

```bash
hospital-management-system/
│
├── backend/
├── frontend/
```

## How to Run the Project

### Step 1: Download the Project

Clone the repository or download the ZIP file.

```bash
git clone <repository-link>
```

## Backend Setup

### Step 2: Open Backend Folder

```bash
cd backend
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Create .env File

Create a `.env` file inside the backend folder.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Step 5: Start Backend Server

```bash
npm start
```

Backend runs on:

```bash
http://localhost:5000
```

## Frontend Setup

### Step 6: Open Frontend Folder

```bash
cd frontend/frontend
```

### Step 7: Install Dependencies

```bash
npm install
```

### Step 8: Start Frontend

```bash
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```
